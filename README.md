# SpeedType - Python Tkinter Typing Speed Test

A simple, modern, all-in-one desktop Typing Speed Test application built with Python and Tkinter in **under 200 lines of code**.

---

## 🚀 Key Features

- **⚡ Real-Time Character Highlighting**: Correct characters highlight in green, errors in red with background tint, and the current letter is underlined.
- **📊 Live Metric Cards**: Real-time display of WPM (Words Per Minute), Accuracy (%), Time Left (seconds), and Errors.
- **⏱️ Multiple Timer Modes**: Toggle between 30-second and 60-second test modes.
- **🔀 Curated Passages**: Random paragraph selection to practice on different texts.
- **🏆 Scorecard Dialog**: Pop-up window displaying final speed, accuracy, errors, and an achievement rating.
- **🎨 Modern Dark UI**: Clean Dracula/Cyber theme (`#1e1e2e`) with high-contrast typography.
- **📦 Single File (Zero Dependencies)**: Written in one file (`main.py`) using only Python's built-in `tkinter`, `time`, and `random` libraries. No `pip install` required!

---

## 🖥️ How to Run

Open PowerShell or Command Prompt in this directory:
```powershell
python main.py
```
